Cyberattaque contre l’Agence France-Presse

Victime
Agence France-Presse (AFP)
Attaque
Intrusion informatique
Criticité
importante

L’Agence France-Presse a suspendu l’accès à son portail AFP Forum à la suite d’une intrusion informatique survenue dans la nuit du 25 au 26 novembre 2026. Des solutions de secours ont été activées pour maintenir la diffusion des contenus à ses abonnés. Les investigations se poursuivent avec l’aide d’experts externes pour déterminer l’origine et la portée exacte de l’incident.

Intrusion chez l’éditeur SAP via des jetons d’accès volés

Victime
SAP
Attaque
Vol de tokens d’authentification (GitHub)
Criticité
importante

L’éditeur de logiciels SAP a confirmé la détection d’activités suspectes dans son environnement informatique. Des attaquants auraient exploité des jetons d’authentification dérobés à des salariés pour accéder à des dépôts de code source sur GitHub dans le cadre du projet interne « Project Granite ». L’entreprise indique qu’aucune donnée client n’a été compromise à ce stade.

Faille critique d’élévation de privilèges dans le noyau Linux

Victime
Serveurs Linux (service NFS)
Attaque
CVE-2026-99362 (vulnérabilité NFS2ROOT)
Criticité
importante

Une vulnérabilité critique vieille de 12 ans, désignée sous le nom de CVE-2026-99362, a été identifiée dans le serveur NFS (Network File System) du noyau Linux. Elle permet à un attaquant distant d’obtenir un privilège root (administrateur système) sur les hôtes exposés. L’application des mises à jour de sécurité est vivement recommandée pour prévenir tout risque d’exploitation.

BleepingComputer, 27 nov.

Today’s word is USN Journal (Update Sequence Number Journal) 🔎

Définition : Le journal USN est un composant du système de fichiers NTFS de Windows qui enregistre de manière séquentielle toutes les modifications effectuées sur les fichiers et répertoires.

Exemple : Lorsqu’un attaquant dépose puis supprime un outil de reconnaissance sur un système, une trace décrivant la création et l’effacement de l’exécutable reste inscrite dans le flux $J de ce journal.

Côté DFIR : Cet artefact de forensic (investigation numérique) permet de reconstituer l’activité sur un disque dur même si les métadonnées de la MFT (Master File Table / table de fichiers maîtres) ont été écrasées. Il aide l’analyste à repérer les dépôts de malwares, la manipulation d’archives ou la suppression de preuves lors d’un incident.

Le chiffrement inviolable nuit-il au bien commun ?

Le chiffrement de bout en bout garantit la confidentialité stricte des échanges et protège les infrastructures stratégiques contre l’espionnage local et distant. Néanmoins, les services d’enquête déplorent que l’impossibilité technique de déchiffrer les communications bloque la lutte contre le crime organisé et les menaces étatiques. Doit-on accepter d’affaiblir la sécurité de tous pour garantir la capacité d’investigation légitime de l’État ?
